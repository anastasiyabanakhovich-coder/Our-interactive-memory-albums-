# Наша история ♡

Готовый статический сайт с книгой, 11 сканами (обложка + 10 страниц), анимацией перелистывания, синтезированным звуком шелеста и встроенным редактором.

## Запуск

Распакуйте ZIP полностью и откройте `index.html` двойным щелчком. Никаких npm, Vite, React или серверной сборки не требуется. Сайт также работает на статическом хостинге.

## GitHub + Cloudflare Pages

Загрузите `index.html`, `style.css`, `app.js` и папку `assets/` в корень репозитория. В Cloudflare Pages выберите подключение к GitHub. Framework preset: None; Build command: оставить пустым; Output directory: `/` (или `.` в зависимости от интерфейса). Не выбирайте Vite.

## Редактор

Нажмите «Редактор ↗». Можно добавлять альбомы, загружать страницы, менять их порядок стрелками, удалять страницы и добавлять интерактивные области кнопкой ✦. В редакторе обведите область мышью/пальцем, задайте текст письма либо загрузите изображение и сохраните. При чтении нажатие на область откроет содержимое.

## Важно о публикации

Редактор **локальный**, сохраняет данные в localStorage браузера, не синхронизирует изменения между устройствами и не защищён авторизацией. Публичные посетители не могут менять исходные файлы сайта через редактор, но могут редактировать свою локальную копию. Кнопка «Экспорт JSON» создаёт резервную копию со всеми загруженными изображениями. Чтобы публиковать новые страницы для всех, потребуется интеграция Supabase Storage + Database + Auth с корректными RLS-политиками и отдельным механизмом публикации. Это пока НЕ подключено.

Из-за ограничений localStorage большие объёмы изображений могут перестать сохраняться. Регулярно экспортируйте JSON. Не загружайте приватные фотографии на публичный сайт, если не готовы делиться ими с любым посетителем по ссылке.

## Особенности

Анимация перелистывания реализована средствами CSS 3D; звук синтезируется Web Audio API и включается кнопкой после действия пользователя. Для интерактивных писем используется открытие поверх страницы; физическое вытягивание бумажного элемента ещё не реализовано.
