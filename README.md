# Наша история ♡

Интерактивная библиотека фотоальбомов с редактором. Сайт адаптирован для телефона и компьютера.

## Возможности
- Несколько альбомов, обложки, названия и описания.
- Загрузка отдельных JPG/PNG/WebP-сканов, в том числе нескольких сразу.
- Перелистывание кнопками, стрелками клавиатуры и свайпом; лёгкая анимация смены страницы.
- Интерактивные прямоугольные области поверх скана: открывают текст, фотографию или видео по прямому URL.
- Добавление, удаление, перестановка страниц; редактирование подписи.
- Отдельный редактор `/#/editor`.
- Режим без облака для тестирования: данные в localStorage, резервная копия JSON.
- Облачный режим Supabase: публичный просмотр по ссылке, вход редактора через Supabase Auth и защита записи RLS.

## Запуск на компьютере
1. Установите Node.js 20+.
2. В папке проекта выполните `npm install` и `npm run dev`.
3. Откройте адрес, который покажет терминал (обычно `http://localhost:5173`).
4. Перейдите в «редактор». Без Supabase это демо: всё сохраняется **только в браузере этого устройства**, а большие фотографии могут переполнить хранилище. Используйте «Экспорт JSON» для резервной копии.

## Настройка облака — необходима для общего доступа
1. Создайте проект на https://supabase.com .
2. Откройте **SQL Editor**, вставьте и выполните `supabase.sql`.
3. В **Authentication → Providers → Email** включите вход по email. Создайте администратора через **Authentication → Users → Add user** (или зарегистрируйте его безопасным способом). Не включайте свободную регистрацию, если она не нужна.
4. Скопируйте UUID администратора из **Authentication → Users**. В SQL Editor выполните:
   `insert into public.app_admins(user_id) values ('UUID_АДМИНИСТРАТОРА');`
5. В **Project Settings → API** возьмите Project URL и **publishable/anon key**. **Не используйте service_role или secret key в браузере!**
6. Скопируйте `.env.example` в `.env` и заполните:
   `VITE_SUPABASE_URL=https://...supabase.co`
   `VITE_SUPABASE_ANON_KEY=...`
7. Перезапустите `npm run dev`. Перейдите в редактор и войдите под аккаунтом администратора. Добавьте альбомы и сканы.

**Доступ по ссылке:** облачный режим делает альбомы и изображения публично читаемыми без входа. Это означает, что любой с адресом сайта может смотреть материалы, а прямые ссылки на изображения не являются секретными. Не загружайте туда конфиденциальные данные. Если нужна настоящая приватность, потребуется другая конфигурация: авторизация зрителей и закрытое хранилище.

## Публикация через GitHub + Cloudflare Pages
1. Создайте приватный или публичный репозиторий GitHub, загрузите туда файлы проекта. **Не загружайте `.env`** (он исключён в `.gitignore`).
2. В Cloudflare → Workers & Pages → Create → Pages → Connect to Git подключите репозиторий.
3. Build command: `npm run build`; output directory: `dist`.
4. Добавьте в Cloudflare → Settings → Variables and Secrets две переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` со значениями из Supabase. Пересоберите сайт.
5. В Supabase → Authentication → URL Configuration укажите адрес опубликованного сайта в Site URL (для корректной авторизации и email-ссылок).
6. После публикации отправьте ссылку партнёру. Редактор находится по адресу `https://ВАШ-САЙТ/#/editor`.

## Как сделать интерактивную страницу
1. Откройте редактор → альбом → «Страницы» → «Добавить страницу».
2. Загрузите скан. Нажмите «Добавить область».
3. Нажмите на верхний левый, затем на нижний правый угол нужной зоны на изображении.
4. Выберите «Текст», «Фотография» или «Видео». Для фото/видео используйте **прямую ссылку на файл**, не ссылку на страницу YouTube.
5. Нажмите «Сохранить страницу». Посетитель сможет нажать на выделенную зону и увидеть содержимое.

## Ограничения текущей версии
- Это **первая рабочая версия**. Перелистывание реализовано как анимированная смена листа, без полноценной физической 3D-модели бумажной книги.
- Выдвижные бумажные вкладки и сложные раскладушки пока не воспроизводятся; интерактивность реализована через открывающиеся окна.
- Позиции интерактивных областей задаются двумя нажатиями по изображению, без перетаскивания и изменения размера после создания.
- Для вложений внутри интерактивной области сейчас нужен прямой URL изображения или видео.
- В демо-режиме большие изображения ограничены квотой localStorage. Для настоящей библиотеки используйте Supabase.
- В облачном режиме удаление страницы/альбома не удаляет старые файлы из Storage автоматически; при необходимости очищайте их через панель Supabase.
